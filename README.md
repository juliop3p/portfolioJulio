# Portfólio Julio Cesar 💻

Boas vindas ao repositório do meu portfólio pessoal! Este projeto foi recentemente modernizado para refletir meu atual momento de carreira e minhas habilidades focado em engenharia de software Front-end.

[🌍 Acessar Portfólio](https://portfoliojulio.netlify.app/)

## ✨ Visão Geral

O objetivo principal deste projeto é ser um cartão de visitas digital de alta performance, apresentando:
- Minha trajetória e interesses acadêmicos atuais.
- Minha stack de tecnologias.
- Projetos em destaque.

## 🚀 Tecnologias e Ferramentas

Esta versão (v2) é uma evolução do antigo projeto feito com Bootstrap. Agora, ele é focado em performance e customização utilizando as seguintes tecnologias:

- **HTML5** Semântico
- **Tailwind CSS** (via CDN para estilização utilitária e ágil)
- **Vanilla JavaScript** (Interatividade e animações)
- **FontAwesome** (Ícones SVG/Webfonts)
- **Google Fonts** (Inter & Space Grotesk)

## 🎨 Design & UI/UX

O design adotado prioriza o **Dark Mode** 🌙, utilizando fundos escuros, efeitos de *glassmorphism* suaves e acentos de cor neón (Verde `#00ff66`) para dar destaque as informações cruciais e criar uma estética "developer-first".

### Funcionalidades
- **Totalmente Responsivo:** Adaptado perfeitamente para Desktop, Tablets e Mobile.
- **Microinterações:** Efeitos de hover nos cards, botões com translate e links sociais interativos.
- **Navegação Contínua:** Menu *sticky* e *smooth-scroll*.

## 🛠️ Como rodar localmente

Como o projeto é um site estático sem processos de *build* pesados, rodar localmente é extremamente simples:

1. Clone o repositório:
```bash
git clone https://github.com/juliop3p/portfolioJulio.git
```
2. Entre no diretório do projeto:
```bash
cd portfolioJulio
```
3. Utilize qualquer servidor estático local. Se tiver o Python instalado, por exemplo:
```bash
python3 -m http.server 8080
```
4. Acesse no navegador em `http://localhost:8080`.
